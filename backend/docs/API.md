# SmartRoute API Documentation

## Overview

SmartRoute provides REST API endpoints for managing locations. Each location contains an ID, a name, latitude, and longitude.

**Base URL:** `http://localhost:8080`

**Content type:** `application/json` for request and response bodies where applicable.

## Location Model

A location is represented as:

```json
{
  "id": 1,
  "name": "Tempe Station",
  "latitude": 33.4255,
  "longitude": -111.94
}
```

| Field       | Type    | Description                                          |
| ----------- | ------- | ---------------------------------------------------- |
| `id`        | Integer | Unique location identifier generated by the database |
| `name`      | String  | Name of the location; cannot be blank                |
| `latitude`  | Number  | Latitude between -90 and 90                          |
| `longitude` | Number  | Longitude between -180 and 180                       |

## Endpoints

### 1. Get All Locations

Retrieves all locations.

- **Method:** `GET`
- **Path:** `/api/locations`
- **Request body:** None
- **Success status:** `200 OK`

**Example request**

```http
GET /api/locations
```

**Example response**

```json
[
  {
    "id": 1,
    "name": "Tempe Station",
    "latitude": 33.4255,
    "longitude": -111.94
  }
]
```

If no locations exist, the endpoint should return an empty array.

### 2. Get a Location by ID

Retrieves one location using its ID.

- **Method:** `GET`
- **Path:** `/api/locations/{id}`
- **Request body:** None

**Success status:** `200 OK`

**Example request**

```http
GET /api/locations/1
```

**Example response**

```json
{
  "id": 1,
  "name": "Tempe Station",
  "latitude": 33.4255,
  "longitude": -111.94
}
```

**Error status:** `404 Not Found` if the location does not exist.

Example error response:

```json
{
  "status": 404,
  "message": "Location not found",
  "path": "/api/locations/999999"
}
```

### 3. Create a Location

Creates a new location.

- **Method:** `POST`
- **Path:** `/api/locations`
- **Content type:** `application/json`

**Example request**

```http
POST /api/locations
Content-Type: application/json
```

```json
{
  "name": "Tempe Station",
  "latitude": 33.4255,
  "longitude": -111.94
}
```

**Success status:** `201 Created`

The response body contains the generated location ID.

**Validation rules:**

- `name` must not be blank.
- `latitude` must be between -90 and 90.
- `longitude` must be between -180 and 180.
- `latitude` and `longitude` are required.

**Error status:** `400 Bad Request` if request validation fails.

### 4. Update a Location

Updates an existing location.

- **Method:** `PUT`
- **Path:** `/api/locations/{id}`
- **Content type:** `application/json`

**Example request**

```http
PUT /api/locations/1
Content-Type: application/json
```

```json
{
  "name": "Updated Tempe Station",
  "latitude": 33.43,
  "longitude": -111.95
}
```

**Success status:** `200 OK`

**Error status:** `404 Not Found` if the location does not exist.

Invalid request data should return `400 Bad Request`.

### 5. Delete a Location

Deletes a location using its ID.

- **Method:** `DELETE`
- **Path:** `/api/locations/{id}`

**Example request**

```http
DELETE /api/locations/1
```

**Success status:** `204 No Content` when a location is deleted successfully. The response has no body.

**Error status:** `404 Not Found` if the location does not exist.

## Error Response Format

When an error is handled by the global exception handler, the response uses this JSON structure:

```json
{
  "status": 404,
  "message": "Location not found",
  "path": "/api/locations/999999"
}
```

| Field     | Type    | Description                        |
| --------- | ------- | ---------------------------------- |
| `status`  | Integer | HTTP status code                   |
| `message` | String  | Description of the error           |
| `path`    | String  | Request path that caused the error |

## Notes

- The database generates location IDs.
- Coordinates must use valid latitude and longitude ranges.
- Error responses depend on the exception-handling behavior configured by the backend.
- This documentation describes the location endpoints; other SmartRoute endpoints may be documented separately.
